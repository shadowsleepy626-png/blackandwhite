# 第一场公交车站 · 七张分镜图

本包按用户这次指定的7个画面制作，以新上传的公交站图片为环境依据，以保存的人物原图固定白辞、黑棠、崔赫。此场崔赫为鸭舌帽、皮夹克A套，不使用第三四场西装。

## 打开与使用

解压后双击 `index.html`，即可在Safari或Chrome离线浏览七张图，并保存单张PNG。所有PNG保留生成时的原始文件，未重新压缩。图片均为1672×941的横屏画面。

图片中含本次明确要求的令牌生平文字、韩文公交广告；没有套用此前全片“画面无文字”的默认规则。生平的姓名、年龄、职业和死因是用于画面测试的虚构道具信息，未写回源剧本，可后续修改。广告为韩文旅游文案，不对应实际广告客户。

第6、7张使用全冷色气氛。第7张在第6张基础上制作，保留四人位置，公交车从画面右边进入并朝左驶过。

本包为待审核成图；不表示用户已确认定稿。第三、七张早期版本未混入本包。

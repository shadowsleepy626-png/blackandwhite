# EP01 v0.4 场景资产包 · 第001套

本套共8张PNG：六处主场景，加街头长椅、办公室对话的两个补充机位。其中4张为前批环境样图核对后复用，4张为本次新生成。所有图片按原始生成文件保存，没有重新压缩或改画。

全部为无人环境底图，未生成本批人物分镜，尚待用户审核，不视为场景已定稿。

## 如何使用

1. 解压后双击 index.html，用Safari或Chrome离线浏览全部图片。
2. 每次生成具体镜头时，附带本镜所需的原始人物设定图和对应场景图，分别固定人物与环境。不能只传场景图凭文字重新设计人物。
3. 明确镜头景别、机位、人物站位、单个主要动作。近景允许景深改变，但家具材质、空间关系和主要光线保持连续。
4. 人物未确定时按用户授权使用已上传的原始定妆图先试做；服装临时沿用时须标注。崔赫第三四场最终仍为西装B套，A套试做不能视为B套已定妆。
5. 画面文字后期添加；尤其结尾档案“李允熙”不依赖生图写字。匿名房间后续镜头不能露出人脸或增加可辨身份的饰品。
6. shot-scene-map.csv是86镜对应的底图建议，不代表这些镜头已经生成。

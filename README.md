# EP01 分镜审阅资料

本分支仅用于下载已完成的分镜提案，不包含原始角色参考图片。

## 下载到 Mac

在 GitHub 分支页面点击 Code → Download ZIP。解压后双击 index.html，用 Safari 或 Chrome 打开。

网页包含全部 82 镜，可筛选场次、搜索对白、复制提示词和打印。无需安装软件，不需要运行服务器。

- index.html：可离线打开的分镜网页
- EP01_整集分镜表.xlsx：Excel 分镜表
- EP01_文字分镜审阅稿.pdf：PDF 文字审阅稿
- EP01-storyboard.zip：上述文件的独立压缩包
